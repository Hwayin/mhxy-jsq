# v0.3 装备精细管理

角色页「装备管理」分为装备、灵饰、上古玉魄，可按类型筛选；新增明细会沿用当前筛选类型。编辑页直接展示对应的属性选择项，无需展开补充属性。

| 类型 | 选择属性 |
| --- | --- |
| 装备 | 部位、等级、宝石类型、宝石锻数、套装效果、特技、特效多选 |
| 灵饰 | 部位、等级、星辉石锻数、钟灵石套装、钟灵石等级 |
| 上古玉魄 | 阳玉 / 阴玉、五色灵尘锻数、玉魄技能多选、奇袭内容多选 |

选项弹层提供搜索；套装按变身术、变化咒、附加状态、追加法术分组。单选点击立即应用，多选点击确认后应用；取消不改变原选择。点击「未配置 / 清空」移除属性。名称选项支持补充未收录名称，等级和锻数使用预置选择。

玉魄法术按所属角色门派提供选项；阳玉提供奇袭特技，阴玉提供奇袭道具。旧值即使不在新列表中，也会显示在「已保存」分组中，不自动丢弃。玉魄强化技能与具体奇袭内容分别记录，多选仅记录同一件玉魄上的技能与奇袭内容。灵饰选定等级后，星辉石候选锻数按等级 / 10 展示，未指定等级时提供 0～16 锻。装备提供 0～30 锻，兼容无级别等不同配置；五色灵尘提供 0～15 锻，钟灵石提供 1～8 级。

实际灵力、魔力、伤害等数值仍可写入「补充数值 / 属性说明」。配置属性只作记录与对比，不改变金额或根据锻数自动推算成本。整号随号资产仍不重复计价。装备、灵饰、玉魄禁止组合购入；组合方式仅供其他分类使用。

## 单件约束与部位完整度

每条装备记录仅对应一件实物。装备必须选择武器、头部、项链、衣服、腰带、鞋之一；灵饰必须选择戒指、耳饰、手镯、佩饰之一；玉魄必须选择阳玉或阴玉。移除装备套装、前排灵饰、后排灵饰等模糊部位选项。表单隐藏装备组合开关，业务写入也拒绝组合及缺少部位的装备，切换分类不能把组合自动变为单件。

角色页展示已逐件记录的部位数量及缺失部位，按部位去重；旧组合、未指定部位记录不计入完整度。完整度表示账本记录覆盖情况，不代表角色当前穿戴状态，备用装备仍可另行录入。

旧组合备份可正常读取和导出，金额仍计入成本；编辑时提示逐件重录，不会把一套直接转换为一件。旧数据应核对分项费用后重录并删除原组合，避免重复计价。

## 兼容与备份

继续使用 v2 备份结构，新增可选属性：`setEffect`、`specialSkill`、`specialEffects`、`starRank`、`bellSet`、`bellLevel`、`dustRank`、`jadeKind`、`jadeEffects`、`ambushSkills`。这些字段已进入校验和导入白名单，角色导出及全账本导出均完整保留。

v1 / 旧 v2 仍可导入；名称、价格、原备注与属性不自动拆分或猜填。旧 `attachment` 类型在页面筛选与小计中归入上古玉魄，导入不会改写其原 ID；主动保存明细时使用 `jade` 类型。旧共用 `gemRank` 的灵饰或玉魄属性可回填到对应锻数选择；主动选择或清空新锻数后移除旧宝石字段，避免清空又显示旧值。

切换装备类型时保留其他类型已录属性，切回时仍可恢复；列表按当前类型展示对应属性。用户原测试文件保持原样，完成配置后可点击「导出测试 JSON」覆盖同角色 ID 文件。升级代码后已启动的 `npm run test-data` 服务需要重启，以加载新的导入字段白名单。

## 选项依据

选项离线内置，读取日期：2026-10-08。只提取公开名称和分类，无需登录或实时请求游戏接口。

- [网易藏宝阁公开配置](https://cbg-xyq.res.netease.com/js/game_auto_config.js)：195 个套装效果、69 个特技、18 个特效、53 个钟灵石套装、6 种玉魄强化技能，以及奇袭特技、道具名称。非字符串的内部占位值不作为用户选项。
- [官网装备宝石说明](https://xyq.163.com/introduce/dj008.html)：宝石名称。
- [官网灵饰说明](https://xyq.163.com/introduce/2014/11/6/5015_474275.html)：部位、等级、星辉石强化规则。
- [官网上古玉魄说明](https://xyq.163.com/news/20250416/4999_1227842.html)：阴阳玉魄、强化技能、五色灵尘及奇袭类别。
- [官网奇袭法术表](https://xyq.163.com/news/20250416/4999_1227887.html)：门派法术候选。相同门派的不同流派重复技能合并，流派具体可用性仍以角色实际装备为准。

`scripts/generate-equipment-options.mjs` 只解析已下载到 `unpackage/references` 的官方 JSON 及表格，不执行远程脚本，生成 `lib/equipment-options.uts`。生成器是开发维护工具，日常运行不依赖这些临时下载文件。
