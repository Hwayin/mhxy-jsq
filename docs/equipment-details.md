# v0.4 装备明细与自动命名

装备、灵饰和上古玉魄不再要求手填名称。选择类型、部位、等级和物品后，自动生成明细标题，并随数值、宝石和套装等配置更新。例如：

`110级 金蚕丝裙 · 魔力+27 / 耐力−10 · 舍利子7锻`

物品名称提供搜索和分类，按已选部位、等级过滤；选择只对应一个等级的物品时自动补齐该等级和部位。多等级同名物品不猜填等级。更改部位或等级导致当前物品不匹配时，回到按部位生成的通用名称。未收录物品也可以选择「通用物品（按部位自动命名）」，不需要输入名称。

离线名称表共 445 条：419 条装备、24 条灵饰、2 条玉魄。内容取自网易藏宝阁公开配置，读取日期 2026-10-08；只保留名称、类别、等级和 ID，不依赖游戏登录。部分未提供确定等级的旧变体没有猜测补入，后续可更新目录。

## 属性与数值

- 装备绿字：选择体质、魔力、力量、耐力、敏捷，再输入整数点数。同一属性不重复，最多五项。
- 灵饰附加属性：选择伤害、法术伤害、速度、气血、防御等，再输入数值。同一属性可以分别记录多条。
- 玉魄数值属性：选择伤害、抗物理、抗法术等，再输入数值，可切换点数 / 百分比。

点击「＋ 添加属性」增加一行，选择属性、填写数值；点击左侧正负号切换正值 / 负值，支持 0。每行可单独删除。属性和数值必须一起填写；一般数值最多两位小数，装备五种绿字使用整数点数。宝石、套装、特技、特效等原有选择方式继续使用。

名称只用于展示和识别，不会推算或改变成本。一件装备一条记录、必选具体部位及部位缺失提示仍然有效。

## 旧数据与备份

新增 `attributes.itemId`、`attributes.itemName`、`attributes.greenAttributes`。每条数值属性由 `kind`、`value` 和可选 `unit` 构成，百分比单位为 `%`，缺省代表点数。导入时保留允许的字段，忽略未知嵌套字段。

新增 `nameGenerated` 标识自动名称；编辑旧装备时，保存后原手填名称保留在 `originalName`，编辑页和明细卡均可查看。加载和导入旧文件不会直接改写名称或价格；仅主动保存编辑后的单件装备时生成新名称。原文字属性、备注与说明仍保留，不自动猜测或拆分文字中的数值。

继续使用 v2 备份结构，兼容 v1 / 旧 v2。角色 JSON 和全账本 JSON 均完整恢复物品、数值和名称元数据。本机导出服务需使用更新后的代码，已重启 / 启动服务后可继续按同角色 ID 覆盖文件。

## 验证与版本

33 项业务测试覆盖物品目录、名称生成、正负数与零、长度限制、数值校验、重复属性规则、旧字段与备份往返，以及成本保持。隔离浏览器流程覆盖真实物品选择、无需名称输入、数值修改与删除、负值、灵饰重复属性、玉魄百分比、编辑回填、筛选变化及从空账本恢复。测试导出写入临时目录，未改写用户浏览器或角色文件。

版本升为 `0.4.0` / `400`，Android 使用既有包名与签名证书。Web / Android 编译及原有账本回归见 `validation.md`。本次没有提交云打包或执行真机验收。

## 选项来源与更新

- [网易藏宝阁公开物品配置](https://cbg-xyq.res.netease.com/js/game_auto_config.js)：`equip_info`、`wjd_equip_equip_type` 的物品名称、等级和类型，灵饰及玉魄数值属性名称。
- [官方灵饰说明](https://xyq.163.com/introduce/2014/11/6/5015_474275.html)：灵饰部位及强化说明。
- [官方上古玉魄说明](https://xyq.163.com/news/20250416/4999_1227842.html)：阴阳类型及数值属性。

开发时可用 `scripts/generate-item-catalog.mjs` 解析本机下载的官方配置并生成 `lib/item-catalog.uts`，不执行远程脚本。日常 App 运行使用离线目录。
