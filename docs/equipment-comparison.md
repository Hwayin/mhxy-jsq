# v0.5 基础属性、装备贡献与同部位对比

版本：0.5.0 / 500。计算范围按用户选择为装备对角色属性的贡献与换算。

## 使用

1. 在角色页点「设置种族 / 经脉换算」，选择角色种族。需要固伤比较时，确认对应技能、经脉适用后启用固伤基础换算；系数可自行校准。
2. 编辑单件装备。武器填未含宝石的伤害和命中，项链填初灵，防具填初防御及对应白字；初始值包含已存在的熔炼。空白表示未知，填 0 表示确认该项为零。
3. 选择宝石和锻数，编辑页实时显示初始值、宝石增量、强化后数值。混镶时，两种宝石各填各自占用的段数，两项相加为总锻数。
4. 灵饰、玉魄先选择基础词条，再逐条记录附加词条。默认「当前成品值」，不会再次加星辉石 / 灵尘；选择「初始值＋强化」时填写每条初始值和每级增量。尚未确认的增量留空，成品结果显示「未完整填写」。
5. 玉魄成品值请填当前人物实际生效值；物品描述中的数值可能受人物等级溢出规则影响。若要由初始属性计算，改用初始模式。
6. 角色页在两件同类型、同部位的记录上点「加入对比」，查看成本与成品属性。灵饰重复词条按同名、同单位汇总，基础词条单独比较。对比仅供查看，不改变账本的计价规则。

## 列表卡片与详情

装备卡片只展示物品名 / 部位、等级、成本、计价标记及最多 3 项关键属性。自动生成的完整配置名称、初始值与强化增量、全部词条、套装、特技、特效、计算公式、日期与备注放到「详情」页。点击卡片或「详情 ›」即可打开；详情中仍可编辑，返回后重新读取最新记录。

卡片默认跟随门派设置展示偏好：龙宫等默认法系；大唐等默认物理；女儿、普陀、地府、无底洞默认固伤；其他门派默认辅助 / 封系。优先显示对应的输出 / 治疗 / 封印属性，再显示速度、气血、防御等通用生存属性。这个默认值不限定门派玩法：在「卡片关注 → 切换」中可按当前流派临时选择法系、物理、固伤或辅助 / 封系，重新加载页面后恢复跟随门派。

灵饰同名属性合计后展示，玉魄同样使用已配置的强化口径。没有适用词条时显示简短提示；未知强化结果显示「待完善」。切换展示偏好不修改角色、装备、换算系数或成本，完整对比表保留全部指标。

## 白字与宝石

| 项目 | 计算 |
| --- | --- |
| 武器伤害 | 初伤 + 太阳石段数 × 8 |
| 武器命中 | 初命中 + 红玛瑙段数 × 25 |
| 武器综合总伤 | 强化后伤害 + 强化后命中 ÷ 3，不含绿字力量 |
| 项链灵力 | 初灵 + 舍利子段数 × 6 |
| 防具防御 | 初防御 + 月亮石段数 × 12 |
| 气血 / 速度 | 对应初始值 + 光芒石段数 × 40 / 黑宝石段数 × 8 |

其他已收录宝石同样按属性与可镶嵌部位计算。缺少类型、锻数、初始值，或宝石部位不匹配时，相应结果保持未知；未知宝石不按零加成给出完整结果。物品基础防御与宝石新增灵力、气血等分开显示。

宝石增量及可镶嵌部位来源：[网易官方宝石介绍](https://xyq.163.com/introduce/dj008.html)。

## 法伤、种族与固伤模型

武器法伤贡献基础估算：

`强化后伤害 × 0.25 + 魔力 × 0.7 + 力量 × 0.4 + 体质 × 0.3 + 耐力 × 0.2`

命中与红玛瑙不参与这个武器法伤基础模型。伤害换算系数可在角色中修改；灵力模型的绿字系数不按种族改变。模型参考[原创武器对比分析](https://xyq.17173.com/content/05132020/180046738.shtml)及[玩家灵力实测](https://games.sina.com.cn/o/z/xyq/2009-12-10/1146358091.shtml)。这些属于经验研究，估算值不等于游戏服务器最终面板或战斗伤害。

绿字力量的等效伤害、耐力的防御贡献使用种族近似预设，允许独立校准：

| 种族 | 力量 → 伤害 | 耐力 → 防御 |
| --- | --- | --- |
| 人族 | 0.67 | 1.5 |
| 魔族 | 0.77 | 1.3 |
| 仙族 | 0.57 | 1.6 |

力量预设是比较用的近似值，不将两位小数当成服务器精确成长。未设置种族且未自定义系数时，相应等效贡献保持待计算。

固伤默认关闭，启用后使用「伤害 × 门派系数 + 敏捷 × 门派系数」的对 NPC 基础模型：

| 门派 | 伤害系数 | 敏捷系数 | 适用条件 |
| --- | --- | --- | --- |
| 普陀山 | 0.24 | 0.7 | 五行法术基础模型，伤害换算需借灵，只计算武器伤害 |
| 女儿村 | 0.18 | 0.5 | 雨落寒沙基础模型，伤害换算需暗伤 |
| 阴曹地府 | 0.15 | 0.35 | 阎罗令基础模型，需要适用的阎罗经脉 |
| 无底洞 | 0.25 | 0.7 | 夺命咒秒脉基础模型，奶脉需单独校准 |

基础预设参考[叶子猪原创装备收益分析（2023）](https://xyq.yzz.cn/focus/202301/1688370.shtml)及[女儿村原创伤害研究](https://xyq.17173.com/content/06062020/090007525.shtml)。门派、经脉、目标和版本会影响实际换算，预设不是所有流派通用的最终公式。每个角色可覆盖伤害、敏捷系数，未收录门派需自定义。直接「固定伤害」词条单独列出，不与这个基础换算混为最终伤害。

未加入角色完整加点、门派技能、经脉全部增益、修炼、目标防御及抗性、阵法或战斗倍率。记录和对比的是单件装备的白字、附加属性及条件明确的基础贡献。

## 灵饰与玉魄强化

灵饰仅在初始模式对附加词条应用 `每级增量 × 星辉石段数`，不增加基础词条。每级增量按实际属性填写；没有确认的逐属性资料时不内置猜测值。[网易官方灵饰介绍](https://xyq.163.com/introduce/2014/11/6/5015_474275.html)说明了星辉石强化附加属性的范围。

玉魄初始模式按以下规则计算：

- 每条附加属性与基础属性相同，自动增加 1 级灵尘。
- 生效等级 = `min(实际灵尘等级, 人物等级/10) + max(0, 实际灵尘等级−人物等级/10) × 0.5`。
- 附加成品值 = `初始值 + 每级增量 × 生效等级`；基础词条不叠加灵尘。

依据[网易官方上古玉魄说明](https://xyq.163.com/news/20250416/4999_1227842.html)。例如人物 100 级、镶嵌 10 级、有 1 条附加与基础相同，有效等级为 10.5；初伤害 5、每级增量 2，生效附加伤害为 26。人物等级未知或增量未填时，保持待计算。

## 数据与验证

基础属性保存为 `baseAttributes`；附加属性仍为 `greenAttributes`，每条可含 `perRank`。`valuesStage` 标识成品 / 初始口径；第二宝石为 `extraGem`、`extraGemRank`；角色增加可选 `race`、`calculation`。备份仍为 v2，旧字段缺省兼容，不自动改写历史数值和成本。

角色 JSON 导出及按 ID 覆盖保持原流程。新增字段完整参与导出、导入和上一版本恢复，计算结果即时生成，避免保存过期计算值。原测试角色文件和用户 Chrome 数据未被功能测试改写。

验证记录见 [validation.md](validation.md)，手机尺寸界面见 [equipment-comparison.png](screenshots/equipment-comparison.png)。Web / Android 前端编译通过；APK 云打包及真机交互尚未执行。
