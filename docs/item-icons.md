# PC 端官方物品图标

现有物品目录共 445 条，全部已取得对应的网易藏宝阁 PC 端官方图片：419 个装备、24 个灵饰、2 个上古玉魄。

来源地址模式为 `https://cbg-xyq.res.netease.com/images/big/<物品ID>.gif`，与网易公开页面使用的图片规则一致。必要时回退到 `images/equip/small/`。目录使用已有的官方物品 ID，没有从游戏客户端解包，也没有执行远程脚本。

运行时直接读取项目 `static/items/<ID>.png`，不请求网易服务器。原图保持原始尺寸与透明度，不重新绘制、改色或放大；为原生兼容统一转换为 PNG，GIF 取首帧。两种玉魄虽然地址以 `.gif` 结尾，实际响应为 PNG，已按文件签名正确处理。

`static/items/manifest.json` 记录各物品名称、来源 URL、尺寸、原文件 SHA-256 与 PNG SHA-256。当前图标文件合计约 2.55 MiB。

`lib/item-icons.uts` 仅允许已下载 ID，精确物品名用于旧记录的补充匹配。通用部位、未知 ID 或图片加载失败时显示文字占位，不给旧记录猜配具体装备。

图标应用于角色明细、装备详情、装备录入预览、物品搜索选择器。账本只保存物品 ID 与属性，不将图片写进备份。

更新工具为 `scripts/fetch-item-icons.mjs`；支持通过 `SHARP_MODULE` 指定图片处理库的模块入口，或使用安装的 `sharp` 包。工具核验文件签名并输出完整来源清单；已有图标校验通过时复用本地文件。
