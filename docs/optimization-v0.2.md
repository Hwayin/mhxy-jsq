# v0.2 配置账本优化

2026-10-08，根据实际录入的 129 龙宫样本优化：10 笔明细，累计 ¥2,135.00。

## 起号方式

角色编辑页提供自建起号、裸号购入、整号购入。新角色默认自建；已有记录保留原模式。备注提到「从0起号」而模式仍为购入时，页面提供调整入口。

自建角色填写起号基础投入（可为 0），技能、修炼、坐骑等支出逐笔累计。整号角色继续支持随号资产已包含标记。切换离开整号模式前，需将已包含明细改为独立计价，避免改变统计口径。

## 细分类型

保留装备 / 灵饰、召唤兽、其他投入三大类，增加细分类型：

- 装备 / 灵饰：装备、灵饰、附加投入。
- 召唤兽：召唤兽、召唤兽装备。
- 其他投入：角色养成、坐骑、日常开销、其他。

角色页可按细分类型筛选，并查看当前筛选的新增投入。旧记录显示未细分，编辑时可手动选择；名称识别提供建议，点击采用后才进入表单，保存后生效。

## 组合购入与属性

开启组合购入后，填写整单总价、包含内容和可选件数。金额只计入一次，不乘以件数、不从文字中提取价格。切换回单件购入后，保存记录不携带组合字段。

补充属性默认折叠。装备可记录部位、等级、宝石类型、锻数及关键属性 / 套装；召唤兽可记录类型、主要技能、成长及关键属性 / 套装。名称和原来的自由文本说明继续保留。

## 小计与备份

角色页直接展示三大类新增投入，随号资产参考价单独展示。顶部总额仍为基础投入加新增费用。

v2 JSON 包含新增字段，v1 备份继续可导入。角色 ID 保持不变，导出文件名称与按 ID 覆盖、恢复方式保持一致。已有浏览器存储键保留，读取旧数据不会直接改写存储；用户保存记录时使用 v2 格式。
