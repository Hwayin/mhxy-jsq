# 快速录入

版本 0.8.0 在角色页底部新增「快速录入」，原「＋记一笔」继续提供完整的分步录入。

第一次可以这样操作：

1. 打开一个角色 → 点击「快速录入」。页面优先选中尚未记录的装备部位。
2. 点选本件部位，可填一次等级，例如 100；具体物品可现在选择，也可稍后补齐。未确认的等级、白字、宝石和绿字保持未录入，不猜测数值。
3. 输入本件实际金额，例如 128.90 → 点击「保存并继续」。金额不能为空；填写 0 表示已确认零投入。
4. 上一件已保存到账本；页面清空本件金额、具体物品和备注，优先切到下一未记录部位，等级与随号计价方式保持。输入下一件金额，再保存即可。
5. 灵饰与玉魄直接切类型；召唤兽、其他投入切上方分类，填写名称和金额后连续保存。
6. 点击「完成」回到角色页。在明细菜单中编辑以补齐属性；也可在快速录入页点击「补齐上一件属性 / 编辑」。

整号中已包含的装备/召唤兽，可开启「购号价已包含此资产」，金额作为参考价，不重复计入总投入。开启状态会保留到下一件，请逐件核对；其他投入和裸号不支持该标记。

等级、计价标记按角色记住；购入日期在当前连续录入中保留。全部部位都有记录后，允许继续补录同部位的其他方案。「已有 N 件」仅反映账本记录。快速模式每次仍写入一件，保持备份格式与成本规则。

未保存时返回，可保留快速录入草稿、放弃本件或继续录入。已保存的上一件不会被放弃；快速草稿与三步编辑器的草稿分开。
