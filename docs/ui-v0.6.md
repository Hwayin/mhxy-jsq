# 玉色账本 v0.6

已将设计提案落地为实际 App 页面，主色 `#287565`，页面底色 `#F5F4EE`，暖白卡片、玉色导航及原创云纹。Web 正文使用系统无衬线字体，原生保持系统字体。

## 页面

- 总览：突出累计投入，四类成本改为合并比例条与金额图例；零金额分类仍显示，但不绘制有色分段。
- 账号：保留搜索，加入队伍筛选与角色金额；编辑、删除收进账号菜单。
- 角色：压缩身份和成本摘要，部位记录按需展开；设置、计价说明、JSON 导出和删除角色进入菜单；明细卡保留最多三项关注属性、对比、详情和菜单，底部固定“记一笔”。
- 录入：装备、灵饰和玉魄采用基本信息、属性配置、确认保存三步；基本信息展示类型、部位、等级、物品、金额、计价标记、日期与备注；确认页优先展示金额、计价和最终配置。其他分类、账号及角色继续使用完整表单。
- 详情：加入官方物品图标与关键属性，完整配置、全部换算及成本来源继续保留；计算公式可展开；明细支持编辑和确认删除。
- 备份：统一主题，保持原有导入、导出、上一版本恢复及示例数据规则。

445 个现有物品图标均采用离线官方素材，详情见 [图标来源](item-icons.md)。

## 草稿与返回

选择器打开时返回优先关闭选择器；装备第二、第三步返回到上一步。存在修改时离开编辑页可选择保留草稿、放弃修改或继续编辑。

草稿以记录或所属角色区分，存储在独立的 `mhxy-editor-draft-v1:` 键中，不进入成本统计或备份。重新打开对应表单时可以恢复；成功保存或明确放弃时清除。保存失败保留当前内容。浏览器关闭或系统强制结束不保证保留未明确保存的草稿。

Android 最后一页返回的退出确认保留；并非从编辑页直接退出。固定按钮与选择器的底部安全区通过 `uni.getWindowInfo()` 计算，避免原生蒸汽模式不支持的 CSS `calc + env`。

App / package 版本为 0.6.0，Android versionCode 为 600；账本仍为 v2，没有迁移、清理或改写用户数据。既有整号资产去重、属性换算和 JSON 备份格式保持一致。

## 回归

单元与资源校验使用 `node --test tests/*.test.js`。新版页面回归脚本为 `scripts/smoke-jade-ui.mjs`，支持 `PLAYWRIGHT_MODULE` 与 `PREVIEW_URL`，使用隔离 Edge 上下文。旧 `smoke-*` 脚本保留作为此前版本的流程记录，其选择器按旧界面编写。

验证覆盖官方图标加载、折叠与展开、同部位对比、装备分步新增与编辑、金额保持、草稿保留与恢复及放弃、计价说明菜单、备份恢复和 320px 屏幕宽度。原生键盘、系统手势及真机触控仍需连接 Android 设备验收。
