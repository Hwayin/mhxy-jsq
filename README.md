# 梦幻多开账本

梦幻西游电脑版多开成本记录 App，基于 **HBuilderX + uni-app x 蒸汽模式 + Vue 3**。第一版为本地离线账本，不需要后端或登录。

## 已实现

- 多账号、多角色管理；账号可按队伍分组、搜索。
- 角色记录服务器、门派、等级、游戏 ID、购号价格与备注。
- 装备管理（装备 / 灵饰 / 上古玉魄）、召唤兽、其他投入明细，记录金额、属性、日期和备注。
- 总览、队伍成本、角色成本排行、各类成本占比。
- 裸号 / 整号计价，随号资产可标记「购号价已包含」，避免重复计入。
- 自建起号、裸号购入、整号购入三种起号方式。
- 装备、灵饰、上古玉魄、召唤兽装备、角色养成、坐骑等细分类型与筛选。
- 装备、灵饰、玉魄强制逐件录入并指定部位，显示未记录部位；其他分类仍可组合购入。
- 装备精细属性通过搜索选择录入；装备特效及玉魄奇袭内容支持多选。
- 绿字 / 附加属性先选类型再输入数值，支持负值和逐条编辑；游戏物品名按部位与等级选择，自动生成配置标题。
- 记录装备初伤、命中、初灵、初防御及灵饰 / 玉魄基础词条，实时计算宝石后的数值；支持混合镶嵌。
- 按角色种族与可校准门派系数估算装备贡献，支持两件同部位装备的属性与成本对比；灵饰 / 玉魄区分成品值与初始强化口径。
- 装备卡片按门派精简到最多 3 项关键属性，可切换关注流派；点击详情查看全部配置、公式与备注。
- 角色页直接展示三类新增投入，随号资产参考价单独列出。
- 本地持久化、JSON 备份复制与导入、上一版本恢复。
- Android 在最后一页按系统返回键时确认退出，支持继续使用并防止重复弹窗。
- Android APK 整包更新：启动检查与手动检查、更新说明、下载进度、取消重试、SHA-256 校验及系统安装确认；发布流程见 [在线更新说明](docs/apk-updates.md)。
- 玉色账本界面：紧凑总览、队伍筛选、角色部位折叠、明细菜单、装备三步录入和独立草稿恢复。
- 快速录入：直接点部位填金额，保存后连续录入下一件，保留等级和计价方式，支持补齐属性与独立草稿。见 [操作说明](docs/quick-entry.md)。
- 445 个网易藏宝阁 PC 端官方物品图标离线显示，覆盖现有装备、灵饰和玉魄目录；通用记录使用占位图。
- 角色测试 JSON：本机 Web 导出到固定文件，同角色 ID 直接覆盖；可从文件按角色 ID 恢复，保留其他角色。
- 可选的虚构五开示例；首次运行是空账本，不自动混入示例数据。

## 在 HBuilderX 中运行

1. 使用 **HBuilderX 5.26 或更高版本**。本项目开启 `uni-app-x.vapor`，请勿切换到 VDOM 模式。
2. 选择「文件 → 导入 → 从本地目录导入」，导入 `D:\Mycode\mhxy-jsq`。
3. 打开 `manifest.json`。当前已配置 DCloud AppID `__UNI__A9783A2`，请在 HBuilderX 登录拥有该应用的账号。如果项目类型未自动识别，右键项目重新识别类型。
4. 选择「运行 → 运行到浏览器」先体验录入；也可连接 Android 手机，开启 USB 调试，选择「运行到手机或模拟器」。按 IDE 提示安装匹配版本的 uni-app x 基座。
5. 开始使用：账号页新增账号 → 添加角色 → 角色详情记录装备 / 召唤兽 → 总览查看汇总。
6. 空账本可在「备份」页载入五开示例。示例总投入应为 **¥41,000.00**。

项目采用 HBuilderX 根目录结构，无需 `npm install`；编译依赖由 HBuilderX 管理。`main.uts`、业务 `.uts` 文件使用 JS / TS，保留后缀以兼容本机 5.26。每个页面使用组合式 API。

Web 的 `index.html` 脚本入口应保持为 `/main`，由 HBuilderX 编译真实的 `main.uts`。不要改成 `/main.uts`，否则开发模式可能因脚本 MIME 类型为空而白屏。修正入口后刷新浏览器即可；若仍有旧错误，停止运行后重新「运行到浏览器」。

## 计价规则

`总投入 = 角色购入价 + 未标记为已包含的装备成本 + 未标记为已包含的召唤兽成本 + 其他投入`

金额统一以人民币计价，按整数「分」保存。整号购入的随号资产记录的是参考分项价，不再次累计。已标记随号资产的角色切换为裸号前，需先修改其资产的计价标记。

这里的成本是累计投入，并非当前市场估值。未引入出售回款、收益、游戏币汇率或云同步。手续费、点修、月卡等可作为其他投入分别记录；避免与购号价格里的已含费用重复录入。

自建起号的基础投入可填 0，养成支出逐笔录入。装备按单件记录；其他分类的组合购入只累计整单总价，数量与包含内容不额外计费。装备名称与数值录入见 [v0.4 装备明细](docs/equipment-details.md)，三类属性选择见 [v0.3 装备精细管理](docs/equipment-management.md)；其他配置操作见 [v0.2 配置账本优化](docs/optimization-v0.2.md)。

装备初始属性、宝石加成、法伤 / 固伤基础贡献模型与同部位对比见 [v0.5 装备属性与对比](docs/equipment-comparison.md)。先在角色中设置种族；固伤模型需确认技能 / 经脉条件并启用，系数可校准。估算项只用于装备比较。

## 数据备份

「备份 → 复制账本备份」，把完整文本保存为 JSON 或文本文件。换机后粘贴到导入框，检查记录数量并确认替换。导入会替换整个账本，不合并；修改前保留一个上一版本。

数据只存当前 App / 当前浏览器，浏览器预览与手机不是共享账本。卸载或清除数据前请保存备份；账号使用别名即可，不要保存密码。

### 当前角色测试数据

已将实际录入的龙宫角色保存为 `test-data/roles/muz8mwy5-hilnb0a9.json`。在项目目录运行 `npm run test-data`，然后点击 Web 角色页的「导出测试 JSON」，即可把当前角色写入 `test-data/roles/<角色ID>.json`，同 ID 覆盖同文件。

恢复时，在 Web 备份页点击「从 JSON 文件导入」，选中该文件并确认。角色备份只替换同 ID 角色及其明细，保留其他角色；全账本备份的原有整体恢复方式不变。App 端可以复制角色 JSON，并在备份页粘贴导入。详见 [测试数据说明](test-data/README.md)。

当前备份格式为 v2，兼容导入 v1 文件。旧记录的名称、金额、角色 ID 和原起号方式保留；未细分的记录可在编辑页选择类型或采用名称建议。导出仍按原角色 ID 覆盖对应 JSON。

## Android 安装包

Android 正式 APK 沿用已安装版的实际包名 `uni.app.UNIA9783A2` 和 DCloud 云端证书，四档 PNG 图标、Android 6.0+、32 / 64 位 ARM。原本机自有证书与密码仍保留在忽略的 `.local/signing/`；本轮覆盖更新使用经原 APK 核验的云端证书，身份记录见 `release/android-update-identity.json`。

在项目目录执行 `.\scripts\pack-android.ps1` 只检查配置；登录 HBuilderX 后执行 `.\scripts\pack-android.ps1 -Submit` 才会把资源提交 DCloud，并使用原云端证书构建。也可在「发行 → App-Android/iOS-云打包」窗口手动填写。详细字段、文件路径与步骤见 [Android 打包说明](docs/android-packaging.md)。iOS 尚未配置 Apple 签名。

当前交付是 App 源码与开发基础，安装包生成与真机验收状态见 [验证记录](docs/validation.md)。

本机已配置原云端证书和官方 Vapor SDK，可执行 `.\scripts\pack-android-offline.ps1` 生成正式 APK。增加版本并提交推送后，加 `-Publish` 自动上传并设为 Latest，无须提交云打包任务。首次配置与工具版本见 [本地离线打包](docs/android-offline-packaging.md)。

当前应用版本为 **0.8.2 / 802**，修复快速录入切换召唤兽时的原生崩溃，保留 Android 更新分块校验、官方物品图标和玉色账本。正式本地 APK 已在手机覆盖安装，用户确认账本金额一致且分类切换正常。发布状态与下载步骤见 [APK 在线更新](docs/apk-updates.md)。旧 0.7.1 / 0.8.0 的校验器若提示「安装包大小不匹配」，需要通过浏览器下载新版并覆盖安装一次。

以后先增加版本号、提交并推送代码，再执行 `.\scripts\pack-android-offline.ps1 -Publish`：本机生成 APK、验包、上传 APK 和 `update.json`，并将 GitHub Release 设为 Latest。云端构建也可继续使用 `.\scripts\pack-android.ps1 -Submit -Publish`。已有 APK 可使用 `.\scripts\publish-apk-update.ps1 -Apk "安装包路径"`；加 `-DryRun` 可只预演。详见 [自动发布步骤](docs/apk-updates.md)。

## 目录

```text
App.uvue / main.uts        应用与全局样式
manifest.json / pages.json 应用配置与路由
pages/dashboard           成本总览
pages/accounts            账号与角色
pages/role                角色与资产明细
pages/editor              录入与编辑
pages/backup              备份与恢复
lib/ledger.uts            数据校验、金额与汇总
lib/storage.uts           本地存储
tests                     核心业务测试
test-data/roles           按角色 ID 保存的测试 JSON
docs                      选型与验证说明
```

这是独立成本记录工具，不使用游戏登录或自动操作。物品图标采用网易公开的 PC 端藏宝阁素材，来源与校验清单见 [物品图标说明](docs/item-icons.md)；新版界面与验证见 [玉色账本 v0.6](docs/ui-v0.6.md)。
